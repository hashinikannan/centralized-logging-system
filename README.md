# Centralized Logging System 🚀
> A lightweight, beginner-friendly log aggregation and error investigation platform for distributed services built with **Python 3.13**, **Flask**, and **Vanilla Web Technologies**.

The complete project code and documentation are inside [`centralized-logging-system/`](file:///c:/Users/Hashini.K/Documents/devops/centralized-logging-system).

### Quick Start
To launch the application from here:
```powershell
py run.py
```

Or change directory into the project folder:
```powershell
cd centralized-logging-system
py app.py
```

Then open your browser at:
```text
http://127.0.0.1:5000/
```

### Run Tests:
```powershell
cd centralized-logging-system
py -m pytest -v
```
